# 打砖块游戏

一个使用Pygame开发的经典打砖块游戏。

## 游戏说明

### 游戏目标
通过控制底部挡板，用小球击碎所有砖块获得最高分数。

### 游戏规则
1. **挡板控制**：使用鼠标水平移动控制底部挡板
2. **发射小球**：点击鼠标发射小球，小球会以随机角度向上发射
3. **得分机制**：
   - 小球击中砖块获得10分
   - 挡板击中小球次数越多越好
4. **游戏结束条件**：
   - 小球落地（未被挡板接住）
   - 所有砖块被击碎（获胜）
5. **特殊机制**：
   - 小球击中挡板时，根据击中点偏离挡板中心的距离改变水平速度分量
   - 小球碰到墙壁、砖块、挡板都会反弹
   - 砖块随机分布在屏幕上半部分
   - 碰撞时有音效反馈

### 界面说明
- **初始页面**：显示游戏标题、游戏说明和"开始游戏"按钮
- **游戏页面**：
  - 底部：蓝色挡板
  - 上方：彩色砖块
  - 顶部左侧：显示当前分数和挡板击中次数
  - 顶部右侧：显示剩余砖块数量
- **游戏结束页面**：显示最终分数、挡板击中次数、剩余砖块数量和"重新开始"按钮

## 安装说明

### 环境要求
- Python 3.9+
- Pygame 2.5.2+

### 安装步骤

1. 确保已安装Python 3.9或更高版本

2. 安装依赖包：
   ```bash
   pip install -r requirement.txt
   ```

   或者直接安装pygame：
   ```bash
   pip install pygame==2.5.2
   ```

## 运行说明

1. 进入项目目录：
   ```bash
   cd main
   ```

2. 运行游戏：
   ```bash
   python main.py
   ```

## 技术特点

1. **多线程处理**：使用多线程处理物理更新和音效播放，确保游戏流畅运行
2. **碰撞音效**：挡板碰撞和砖块击碎都有音效反馈（需在sounds目录下放置hit.wav和break.wav音效文件）
3. **响应式UI**：
   - 按钮有悬停效果
   - 文字清晰对齐
   - 色彩搭配美观
4. **智能反弹**：小球击中挡板时，根据击中点位置改变水平速度，增加游戏趣味性
5. **随机砖块**：每次游戏砖块布局随机生成，增加游戏可玩性

## 操作提示

- **移动挡板**：将鼠标左右移动
- **发射小球**：点击鼠标左键
- **重新开始**：在游戏结束界面点击"重新开始"按钮
- **退出游戏**：关闭游戏窗口或按ESC键

## 常见问题

Q: 游戏没有声音？
A: 需要在main目录下创建sounds文件夹，并放置hit.wav（挡板碰撞）和break.wav（砖块击碎）音效文件。如果没有音效文件，游戏仍可正常运行，只是没有声音。

Q: 中文显示乱码？
A: 游戏使用Pygame内置字体，中文显示可能有问题。建议确保系统支持中文字体，或修改ui.py中的字体设置。

Q: 游戏卡顿？
A: 游戏使用多线程处理物理计算，通常不会卡顿。如果遇到卡顿，请确保：
   - 关闭其他占用CPU的程序
   - 确保Python版本为3.9+
   - 确保Pygame版本为2.5.2+
