# 打砖块游戏

一个使用 Pygame 开发的经典打砖块游戏。

## 环境要求

- Python 3.9+
- Pygame 2.0+

## 安装步骤

1. 确保已安装 Python 3.9 或更高版本

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 运行游戏

```bash
python main.py
```

## 游戏说明

### 操作方式

1. **移动挡板**：使用鼠标水平移动控制底部挡板
2. **发射小球**：点击鼠标左键发射小球
3. **开始游戏**：在开始页面点击"开始游戏"按钮或按回车键/空格键
4. **重新开始**：游戏结束后点击"重新开始"按钮或按回车键/空格键

### 游戏规则

1. 小球击中砖块获得 10 分
2. 小球击中挡板边缘会根据位置改变反弹角度，增加游戏变化
3. 消灭所有砖块即可获胜
4. 小球落地则游戏结束

### 计分与统计

- **分数**：每击碎一个砖块得 10 分
- **挡板击中次数**：记录挡板成功接住小球的次数
- **剩余砖块**：显示当前还未被击碎的砖块数量

## 项目结构

```
.
├── main.py              # 游戏主入口
├── requirements.txt     # 依赖文件
├── readme.md           # 本文档
└── game/              # 游戏代码目录
    ├── __init__.py
    ├── ui.py          # UI相关代码（开始页面、游戏页面、结束页面）
    ├── control.py     # 鼠标操作控制代码
    ├── run.py         # 物理引擎（小球碰撞、反弹、音效）
    └── count.py       # 计分系统（分数、挡板击中次数、剩余砖块）
```

## 技术特点

1. **多线程设计**：物理更新和渲染分离，保证操作流畅性
2. **智能反弹**：小球击中挡板时根据位置调整反弹角度
3. **碰撞音效**：墙壁、挡板、砖块碰撞都有不同音效
4. **中文支持**：适配 Mac 系统中文字体，无乱码
5. **随机砖块布局**：每次游戏砖块排列随机生成

## 模块说明

### count.py - 计分模块

- `GameCounter` 类管理所有游戏统计数据
- 记录分数、挡板击中次数、剩余砖块数量

### run.py - 物理引擎模块

- `PhysicsEngine` 类处理所有物理逻辑
- 小球运动、碰撞检测、反弹计算
- 音效生成与播放
- 随机砖块布局生成

### control.py - 控制模块

- `MouseController` 类处理鼠标输入
- 鼠标移动控制挡板位置
- 鼠标点击发射小球

### ui.py - UI模块

- `UIManager` 类管理所有界面渲染
- 开始页面：标题、游戏说明、开始按钮
- 游戏页面：实时分数、砖块、挡板、小球
- 结束页面：游戏结果、统计数据、重新开始按钮

### main.py - 主入口

- `BrickBreakerGame` 类统筹整个游戏流程
- 多线程管理：物理线程独立运行
- 状态管理：开始 -> 游戏中 -> 结束
